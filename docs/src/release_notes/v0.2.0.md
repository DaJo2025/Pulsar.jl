# v0.2.0 release notes

Released: 2026-05-13.

## Highlights

### Native SU(2) / Spin-I propagator suite (new)

Three new low-level propagators in `src/Computation/` short-circuit
matrix-exponential overhead for spin-1/2 and single-spin problems:

- **[`SU2Propagator`](https://github.com/DaJo2025/Pulsar.jl/tree/main/src/Computation/SU2Propagator.jl)** —
  Cayley–Klein scalar propagator for phase-only constant-Rabi pulses on spin-1/2.
  The per-step propagator factors as
  `P_k(φ_n) = [[α_k, -β_n_k*], [β_n_k, α_k*]]` with α/β precomputed once per
  optimization. Per-step cost drops from O(dim³) (matrix exp) to O(4) complex
  muls per offset.
- **[`SpinIPropagator`](https://github.com/DaJo2025/Pulsar.jl/tree/main/src/Computation/SpinIPropagator.jl)** —
  Single-spin scalar propagation for spin-I systems (works for any half-integer
  or integer spin).
- **[`TrotterPropagator`](https://github.com/DaJo2025/Pulsar.jl/tree/main/src/Computation/TrotterPropagator.jl)** —
  Trotter–Suzuki decomposition propagator option for the cases where the
  default `compute_propagator` (LAPACK Hermitian eigendecomposition) is not
  the best fit.

Matching fidelity metrics are in `src/Physics/SU2Objectives.jl` and
`src/Physics/SpinIObjectives.jl`.

A new utility, `src/Utilities/SU2DurationSweep.jl`, scans pulse durations to
locate the shortest pulse that meets a target fidelity for SU(2)-class
problems.

### GRAPE-family kernel refinements

`src/Optimization/Gradient/QOC/GRAPEFamily.jl`, `src/Application/MR/GRAPEState.jl`,
`src/Application/MR/GRAPELindblad.jl`, and `src/Application/MR/OptControl.jl`
received refinements aligned with the new propagator suite. APIs are
backward-compatible; existing scripts continue to work.

`src/Physics/Objectives.jl` and `src/Physics/Gradients.jl` were extended to
dispatch on the new SU(2)/Spin-I metric types.

### Julia 1.12 compatibility

Two fixes for issues exposed by the LAPACK and threading changes in Julia 1.12:

- **`compute_propagator` strided-view fix:** Julia 1.12 reroutes the
  Hermitian `eigen` path through `LAPACK.lacpy!` / `chkstride1`, which now
  requires contiguous columns. Strided views of the form
  `H_total[k, :, :]` (an array slice along the leading axis of a 3-D
  propagator stack) are not contiguous and used to throw
  `matrix does not have contiguous columns`. The fix materializes the input
  via `eigen(Hermitian(Matrix(H)))` inside `compute_propagator`, so all
  callers are safe regardless of view shape.
- **Per-thread buffer sizing fix:** the GRAPE kernels in
  `src/Application/MR/` previously sized per-thread scratch buffers by
  `Threads.nthreads()` while indexing by `Threads.threadid()`. On Julia 1.12
  the default and interactive thread pools can lift `threadid()` above
  `nthreads(:default)`, leading to a `BoundsError` against a 1-element
  per-thread buffer vector. Switched to `Threads.maxthreadid()` across all
  per-thread allocations in `GRAPEState`, `GRAPELindblad`, and
  `GRAPETracking`.

The package's `[compat] julia = "1.9"` is unchanged — the runtime supports
the full `[1.9, 2.0)` range; the fixes target the new code path, not the
version bound.

## Compliance

- `Project.toml` now carries a `[compat]` entry for every entry in
  `[deps]` and `[weakdeps]`, satisfying Julia General registry
  AutoMerge requirements.
- New `.github/workflows/TagBot.yml` automates tagging of registered
  releases.
- `Manifest.toml` is no longer tracked (libraries should not commit it).

## Upgrade notes

Existing user code continues to work. Optional opt-ins:

- Switch your phase-only spin-1/2 GRAPE problem to `SU2Propagator` for
  a substantial speedup over the matrix-exp path.
- Use `Utilities.sweep_su2_duration` to find the shortest pulse meeting a
  target fidelity.
