# v0.2.1 release notes

Released: 2026-05-13.

Patch release fixing Julia 1.12 CI failures that slipped through v0.2.0.

## What changed

The Phase D threadid sweep in v0.2.0 covered `src/Application/MR/` but
missed four matching sites in `src/Optimization/Metaheur/` and
`src/Computation/`. Under Julia 1.12 the default and interactive thread
pools can lift `Threads.threadid()` above `Threads.nthreads(:default)`,
producing a `BoundsError` against per-thread allocations sized by
`Threads.nthreads()`.

Four sites are now sized by `Threads.maxthreadid()`:

- `src/Optimization/Metaheur/Swarm.jl:37` — `pso_optimize` RNG cache
- `src/Optimization/Metaheur/Swarm.jl:149` — `de_optimize` RNG cache
- `src/Optimization/Metaheur/GA.jl:37` — `ga_optimize` RNG cache
- `src/Computation/EnsembleMap.jl:519` — `ensemble_grad!` scratch bufs

This resolves the BoundsError observed in the `PSO feasibility – does
not crash` and `PSO reproducibility with fixed seed` tests on
`julia-version: '1'` (= 1.12.6) in CI. The `PhaseOnlyTests / QC
GRAPEConfig default unchanged` failure that appeared in the same CI run
was a downstream effect of the upstream TaskFailedException leaving
the runtime in a degraded state — expected to resolve with the fix.

## Recommended upgrade path

Anyone using v0.2.0 should bump to v0.2.1. The two releases are
behaviorally identical on Julia 1.10/1.11; v0.2.1 is the version to
register in the Julia General registry.
