v0.2.1 release notes

Released: 2026-05-13.

Patch release. Two independent fixes for Julia 1.12 CI failures that slipped through v0.2.0; behaviour on Julia 1.10/1.11 is unchanged.

1. Complete the threadid sweep

The Phase D threadid sweep in v0.2.0 covered src/Application/MR/ but missed four matching sites in src/Optimization/Metaheur/ and src/Computation/. Under Julia 1.12 the default and interactive thread pools can lift Threads.threadid() above Threads.nthreads(:default), producing a BoundsError against per-thread allocations sized by Threads.nthreads(). Four sites are now sized by Threads.maxthreadid():

  • src/Optimization/Metaheur/Swarm.jl:37 — pso_optimize RNG cache
  • src/Optimization/Metaheur/Swarm.jl:149 — de_optimize RNG cache
  • src/Optimization/Metaheur/GA.jl:37 — ga_optimize RNG cache
  • src/Computation/EnsembleMap.jl:519 — ensemble_grad! scratch bufs

This resolves the BoundsError observed in PSO feasibility – does not crash and PSO reproducibility with fixed seed on julia-version: '1' (= 1.12.6) in CI.

2. Make the QC GRAPEConfig regression test RNG-independent

The Algorithms/PhaseOnlyTests.jl test "QC GRAPEConfig default unchanged" seeded its initial controls via randn(MersenneTwister(2026_04_29), 2, N). Julia 1.12 changed the output sequence of MersenneTwister for the same seed (the stdlib does not promise cross-version RNG stability for non-default seeds). The 1.12 sequence placed the initial controls in a regime where GRAPE's adaptive step size collapsed after ~4 iterations at F ≈ 1.088e-6, well below the test's F > 0.99 threshold.

Fix: drop the RNG entirely and use a hand-crafted sinusoidal initial control set with amplitude in the right ballpark for the target X-gate (total angle ≈ Σ u·dt ≈ π). The test now converges identically on 1.10.3 and 1.12.6 to F = 0.999999996 in 134 iterations.

Verification

  • Julia 1.10.3 local: 867 / 867 tests passing.
  • Julia 1.12.6 local: 866 / 866 tests passing (one test is version-conditional; not a regression).

Recommended upgrade path

Anyone using v0.2.0 should bump to v0.2.1. v0.2.1 is the version to register in the Julia General registry.
